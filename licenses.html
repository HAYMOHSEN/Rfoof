Open-source software used in Rfoof

Rfoof is built with vanilla JavaScript and the following open-source libraries, bundled locally so the app works offline. Their license texts are included in the vendor/ folder.

PDF.js (pdfjs-dist 5.x) — Apache License 2.0 — Mozilla Foundation. mozilla.github.io/pdf.js
Used to render PDF documents and extract text for search.
JSZip 3.10 — MIT License — Stuart Knightley. stuk.github.io/jszip
Used to read Office files (docx/xlsx/pptx), list ZIP archives and create backups.
marked 18 — MIT License — MarkedJS. marked.js.org
Used to render Markdown files.
highlight.js 11 — BSD 3-Clause License — highlight.js contributors. highlightjs.org
Used to color source-code files in the viewer.
Lucide icons — ISC License — Lucide Contributors. lucide.dev
Icon shapes adapted for the interface.
